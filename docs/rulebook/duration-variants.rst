6. Duration Variants
--------------------

6.1 Shorter Game
~~~~~~~~~~~~~~~~

**1.** For a shorter game:

* **(a)** Set the win score to 50.
* **(b)** Set the control mark threshold to 2 marks.

6.2 Longer Game
~~~~~~~~~~~~~~~

**1.** For a longer game:

* **(a)** Set the win score to 100.
* **(b)** Keep the standard control mark threshold at 3 marks.
