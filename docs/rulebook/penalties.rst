5. Penalties
------------

5.1 Penalty Application
~~~~~~~~~~~~~~~~~~~~~~~

**5.1.1** Penalty points are subtracted from the player's score, to a minimum
score of zero.

**5.1.2** If multiple penalties apply to the same shot or situation, only the
highest penalty applies.

5.2 Penalty List
~~~~~~~~~~~~~~~~

**5.2.1** The following penalties apply:

* **(a)** Normal snooker penalties.
* **(b)** A 30 point penalty for any intentional foul or illegal shot made to
  manipulate score, avoid exceeding the win score, reset position, or create an
  easier route to the win score.

**5.2.2** Intentional fouls and illegal score-manipulation shots are arbitrated
by majority vote of the other players.
