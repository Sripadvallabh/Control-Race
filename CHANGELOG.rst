Changelog
=========

0.1.1 - Theme and Structure
---------------------------

Changed
~~~~~~~

* Added a stronger PDF theme with cue-sport accents, improved typography,
  cleaner tables, and page footers.
* Added an explicit front-matter table of contents before the changelog and
  rules.

0.1.0 - Initial Draft
---------------------

Added
~~~~~

* Initial Control Race setup and objective rules.
* Standard snooker-style scoring values and exact-score win condition.
* Color control marks, control limits, controlled-color scoring, and control
  revoke rules.
* Snooker challenge declaration, resolution, and penalty rules.
* Penalty framework, including normal snooker penalties and the 30 point
  intentional foul penalty.
* Shorter and longer duration variants.
* Bookkeeping responsibilities for scores, marks, spotting, corrections, and
  table-state checks.
